# 薄肌饮食教练 Demo

这是一个本地前端 Demo。首次打开先填写身体信息、目标与活动习惯，浏览器会立即估算个人计划；直接打开 `index.html` 时对话使用本地模拟回复，通过本地服务并配置 DeepSeek API Key 后，输入、照片和咨询会由 DeepSeek 处理。

后续开发以 [产品设计文档.md](./产品设计文档.md) 和 [开发计划.md](./开发计划.md) 为依据：先完成前端 F0–F3 的样式与模拟交互，经用户明确确认后，再启动后端 B0–B5。

## 体验首次建档

直接打开 `index.html`，依次填写身体信息、目标、训练与日常活动程度，即可看到“静息消耗 → 维持消耗 → 每日建议”的计算结果。进入应用后，在「我的计划」查看依据，点击「更新身体信息与目标」可以修改并即时重算。新用户的 Today 与 History 从空记录开始；旧版演示自带的样本餐食会在首次建档时移除，用户自己新增的浏览器记录保留。侧栏的「重新体验建档」会先确认再清空当前浏览器中的记录。

计划计算在前端完成，不需要 API Key。静息消耗采用成人 Mifflin–St Jeor 公式，活动等级对应估算系数，目标调整采用温和的演示规则；蛋白质按体重给出参考值，碳水与脂肪为粗略分配。结果是初始估算，不是实测代谢或个体医疗建议；当前通用流程适用于 18 岁及以上的一般成年人。参考：[原始公式论文](https://pubmed.ncbi.nlm.nih.gov/2305711/)、[NIH 成人体重规划工具及适用范围](https://www.niddk.nih.gov/health-information/weight-management/body-weight-planner)、[运动人群蛋白质立场文件](https://pubmed.ncbi.nlm.nih.gov/28642676/)。

使用本地服务预览界面时，打开 <http://127.0.0.1:3000/?preview=1> 可强制使用对话模拟，避免触发 DeepSeek 调用；个人计划仍按填写资料实时估算。去掉 `?preview=1` 才会按 API Key 配置连接真实模型。

## 启动真实模型模式

打开同目录的 `api-key.local.json`，把 `apiKey` 后面的空字符串改为你的 DeepSeek API Key，并保留两侧的英文双引号。`model` 使用 `deepseek-flash`，支持文字、照片和思考模式。这个文件只供本机服务端读取，已经加入 `.gitignore`，不会提交到 Git。不要把 Key 填进网页或聊天消息。

例如文件格式如下（示意值不可用）：

```json
{
  "apiKey": "在这里填写你的 Key",
  "model": "deepseek-flash"
}
```

保存文件后，在终端进入本目录并运行：

```zsh
npm start
```

浏览器打开 <http://127.0.0.1:3000>。看到右上角显示“DeepSeek · deepseek-flash”后即可体验。修改 Key 后需要重新启动服务。也可以用 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL` 环境变量临时覆盖本地配置。

请用上面的本地服务地址体验真实模型；原来的 `file://` 页面仍是本地模拟回复。两个地址的浏览器存储彼此独立，因此原来文件版的历史记录不会自动出现在本地服务版。

模型回复使用 DeepSeek 的流式 Responses API。等待时显示“模型正在思考”；下拉区域会逐步显示 DeepSeek 本轮实际返回的思考文本。如果本轮没有返回思考文本，页面会如实提示。营养判断和记录为估算，仍应允许用户修正。

## 查看交互

- 说“刚吃了两个鸡蛋”，查看记录和 Today 的更新。
- 问“晚上想吃火锅”，查看不修改 Today 的建议。
- 说“米饭其实只吃了一半”，查看餐次修正。
- 上传餐食照片并补充一句话，查看图片输入。
- 在「历史 → 今天」查看已完成的交流、餐次和模型思考过程。

当前数据保存在浏览器本机的 `localStorage`，尚未接入账号或数据库。没有配置 API Key 时，页面仍可使用原有本地模拟流程。

如遇到余额提示，可以登录 [DeepSeek 用量页面](https://platform.deepseek.com/usage) 查看账户状态。
